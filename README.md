## Todo List
Include a very brief summary of your project here. Be sure to include the CSS positioning technique you used, and any required instructions to use your application.
I created a simple todo application to have users keep track of their tasks throughout the week. Users can add, view and delete tasks. You can add the priority level and keep track of the creation date.

I used Flexbox for the main layout, on smaller screens its a single-column layout

instructions:
- you can select tasks by name, priority, and creation date
- you can add tasks by clicking 'Add todo'
- you can delete tasks by clicking 'delete'
- a table is visible on the screen to view all of the user's tasks


## Technical Achievements
- **Tech Achievement 1**: Using a combination of...
The form and the data table are on the same page - when a user adds or deletes a tasks the screen updates without having to reload the page.
The server calculates the deadline based on the priority, it assigns a number of days until its due - high (1), medium (3), low (7).
REST-style API - using GET, post, and DELETE, requests to get, add and delete todos.
With the use of flexbox and a media query it can adapt to smaller screens
